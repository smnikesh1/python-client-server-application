# Python Client-Server Application

## About the Project

This project is a Python-based client-server application that demonstrates communication between a client and a server.

## Technologies Used

- Python
- Socket Programming
- Client-Server Architecture
- MySQL / Database

## Project Structure

- `client.py` - Client-side application
- `server.py` - Server-side application
- `test_database.py` - Database testing

## Key Features

- Client-server communication
- Sending and receiving data
- Server-side request handling
- Database connectivity and testing

### 1. Start the Server

python server.py
